✨ Key Features
🔐
SHA-256 Hashing
Content-based detection. File names are irrelevant — only bytes matter.
⚡
Size Pre-Filter
Skips hashing unique-size files. Reduces I/O by up to 80% on typical folders.
🧵
Multi-threaded
Uses all CPU cores via ExecutorService for parallel file hashing.
🛡️
Soft Delete
Files moved to trash — not permanently deleted. Full undo support.
📂
Multi-folder
Scan multiple directories simultaneously in a single operation.
🔧
File Type Filter
Filter by extension: jpg, png, mp4 — or scan everything.

🧩 Module Breakdown
Module File Layer Responsibility
1 — File Scanner FileScanner.java Service Recursive walk via Files.walkFileTree(). Skips hidden + no-read files. Supports extension filters.
2 — Hash Generator HashGenerator.java Service Groups files by size first, then SHA-256 hashes only size-collision candidates. Multi-threaded via ExecutorService.
3 — Duplicate Finder DuplicateFinder.java Service Orchestrates the full pipeline: Scanner → Size Filter → Hash → Group → ScanResult.
4 — GUI MainWindow.java UI JavaFX interface. Folder selector, scan button, results cards, per-group keep/delete radio, undo button.
5 — File Manager FileManager.java Service Soft delete: moves files to .DuplicateFinderTrash. Undo restores originals. emptyTrash() for permanent cleanup.
Models DuplicateGroup, ScanResult Model Immutable data containers. DuplicateGroup holds hash + file list + keep selection. ScanResult has stats + groups.
Utilities FileUtils.java Util formatSize(), getExtension(), getFileTypeIcon(), truncatePath() — shared across layers.
